# world-map-streaming

Türkiye haritası üzerinde canlı veri akışı, bölge adları, rota çizgileri ve yakınlaştırma (zoom) desteği sunan örnek bir web uygulamasıdır.

## Özellikler

- Türkiye merkezli harita görünümü
- Bölgeler / şehirler için işaretleyiciler
- Rota çizgileri ve canlı akış verileri
- "Merkez" butonu ile haritayı başlangıç konumuna döndürme
- Alan üzerinde tıklayarak bölgelere odaklanma

## Kurulum

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Görünüm

Uygulama, yerel tarayıcıda `http://localhost:5173` üzerinde çalışacaktır.
